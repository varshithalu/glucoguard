# 🩺 GlucoGuard – Smart Diabetes Healthcare Management System

## 📌 Overview

GlucoGuard is a healthcare management platform designed for diabetes patient monitoring, appointment management, medicine ordering, and doctor-patient interaction.

The system supports Admin, Doctor, and Patient modules with secure workflows and healthcare-focused features.

## 🚀 Features

* Admin dashboard management
* Doctor and patient management
* Appointment scheduling
* Medicine ordering system
* Notifications and logs
* Doctor-patient chat system
* Dark mode support
* Healthcare transaction tracking
* Secure authentication and role management

## 🛠️ Tech Stack
React.js
Sass
Next.js
* ---  Blockchain  ---
Solidity 
Metamask

## 👥 User Roles

### Admin

* Add doctors and patients
* Manage fees and appointments
* Monitor platform activity

### Doctor

* Manage appointments
* View patient details
* Communicate with patients

### Patient

* Book appointments
* Order medicines
* Chat with doctors
* Receive notifications

## 🧠 Workflow

1. Admin registers doctors and patients
2. Patients book appointments
3. Doctors manage consultations
4. Medicine orders processed
5. Notifications and logs generated
6. Real-time communication supported
